# Banner artwork

The right panel uses a crop of Sega's original *Rail Chase 2* promotional poster, archived as [Rail Chase 2 artwork](https://backloggd.com/games/rail-chase-2/) via IGDB/Backloggd. Original game artwork and trademarks belong to Sega.

The left panel follows the existing VR4ALL dark-grid title layout. The poster is archival artwork, not a screenshot of VR gameplay. No AI-generated game characters or scenes were added.
